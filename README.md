# 투딸라 링크 모아보기 · 스윙 계산기

일상·캘리그라피·수채화·AI 기록을 남기는 개인 링크 페이지와,
매수가·수량만 넣으면 절반 익절가와 본전 스탑가를 계산해 주는 스윙 계산기입니다.

- 메인: <https://twodollar1004.github.io/> — 링크 모음
- 계산기: <https://twodollar1004.github.io/swing/> — 스윙·본전현금화 계산기

## 구성

```
index.html          링크 모음 페이지
swing/index.html    스윙·본전현금화 계산기 (순수 클라이언트 계산)
.nojekyll           Jekyll 처리 없이 정적 파일 그대로 배포
404.html            없는 주소로 들어왔을 때 메인으로 안내
```

## 계산기 규칙

- 1차 목표 수익률(기본 +5%)에 절반 익절, 남은 절반은 본전 스탑(기본 +0.5%)
- 수수료·증권거래세 반영 토글 (기본 수수료 0.015%, 거래세 0.20% — 요율 직접 수정 가능)
- KRX 호가단위(2023 개편) 적용: 익절가는 반올림, 본전 스탑가는 올림
- 입력값은 브라우저 `localStorage`에만 저장되며 서버로 전송하지 않습니다.

개인 정보(실명·연락처·계좌·보유 종목)는 이 저장소에 포함하지 않습니다.
계산 결과는 참고용이며 투자 판단의 책임은 이용자에게 있습니다.
